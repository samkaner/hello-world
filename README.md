## Sproutlandia

A short, silly, 16-bit-style game built with Godot 4, playable with a
Switch Pro Controller / Joy-Con on a Mac mini. Original characters and art,
inspired by the tone of Mario/Zelda/Kirby (no Nintendo IP used).

Play as Pip, a floaty sprout with a wooden ladle, across 5 short levels, a
mini-boss ("Big Yawn"), a final boss ("Grumbleroot"), and a game-over
screen with jokes instead of despair. Roughly 20-30 minutes start to
finish.

### Running it on your Mac mini

Easiest: launch **Sproutlandia.app** (exported build, installed in
`/Applications`). Pair your Switch Pro Controller or Joy-Con first
(Bluetooth or USB-C both work).

From source instead:

1. Install Godot 4.x (`brew install --cask godot`).
2. Open `project.godot` in Godot and press F5 — or run
   `godot --path <repo> ` from a terminal.
3. Keyboard fallback: arrows/WASD to move, Space/Z to jump, X to attack,
   Esc to pause.

To re-export the app: download the matching export templates in the Godot
editor (or unpack the official `.tpz` into
`~/Library/Application Support/Godot/export_templates/`), then run
`godot --headless --export-release macOS builds/Sproutlandia.app`.

### Project layout

- `project.godot` -- engine config, autoloads, pixel-perfect render settings.
- `scenes/` -- levels, entities (player/enemies/bosses), UI screens.
- `scripts/` -- all GDScript: player controller, enemy/boss AI, level
  building helpers, UI.
- `assets/` -- sprites, tiles, backgrounds, UI art, and chiptune audio --
  all generated by the Python pipelines below (nothing hand-drawn,
  recorded, or sourced externally).
- `tools/pixelart/` -- deterministic Python (Pillow) scripts that generate
  every PNG under `assets/`. Run `python3 tools/pixelart/build_all.py` to
  regenerate them.
- `tools/audio/` -- deterministic pure-stdlib Python synth that generates
  every WAV (sound effects + two music loops) under `assets/audio/`. Run
  `python3 tools/audio/gen_audio.py` to regenerate them.

### Controller mapping note

Godot's joypad button constants follow the Xbox-style "standard gamepad"
layout rather than Nintendo's printed labels. On a Switch controller, the
physical **B** button (bottom face button) triggers jump, and **Y** (left
face button) triggers attack -- see `scripts/systems/InputSetup.gd` for the
full mapping and rationale.

### A note on how this was built

Levels build their own platform/wall geometry and trigger zones
(checkpoints, goals, hazards, doors) from code rather than hand-authored
Godot TileMap/resource files, since the first version was built without
access to the Godot editor itself. It has since been validated with Godot
4.7 on macOS: clean project import, every scene run headless with no
script errors, and rendered frames visually checked (title screen, all
five levels, HUD, parallax). Human playtesting feedback -- especially
difficulty tuning with a real Switch controller -- is still welcome.
